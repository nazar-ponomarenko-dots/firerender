# Консольные команды

Справочник команд. Реестр — таблица `s_cmds` в `src/cmdreg.c:42-127`
(единая для всех статических команд движка) плюс команды самой консоли
(`src/console.c:984-1004`) и команды, зарегистрированные из Lua
(`engine.cmd`). В игре: `help` — список, `help <команда>` — справка.

## Синтаксис

| Правило | Поведение | Источник |
|---|---|---|
| Аргументы | Имя команды — до первого пробела/табуляции, остальное — одна строка аргументов обработчику | `console.c:173-184` |
| `;` | Разделитель команд в одной строке, **кроме** внутренности кавычек (тело `alias`/`bind` может содержать `;`) | `console.c:228-260` |
| Кавычки | Строковые аргументы в `"…"` (имя игрока, тело alias, путь с пробелами) | там же |
| Рекурсия alias | Раскрывается не глубже 8 уровней — защита от `alias a "a"` | `console.c:170-199` |
| Очередь кадров | `wait [N]` откладывает **все последующие команды строки** на N кадров (1 по умолчанию); очередь ограничена `CON_PEND_MAX` | `console.c:95-105, 214-260` |
| Неизвестная команда | `Unknown command "<имя>" (help — список команд)` | `console.c:201` |

`LEFTBRACKET`, `LCTRL`, `LSHIFT`, …) плюс две виртуальные:
`mouse_wheel_up` / `mouse_wheel_down` (`binds.c:47-52`).

## Движение (`+`/`−` пары)

Флаг действий ставится из бинда; `-`-команда снимает ровно тот же флаг
(`cmdreg.c:23-37, 44-61`). Всё читает `camera.c`.

| Пара | Действие |
|---|---|
| `+forward` / `-forward` | Вперёд |
| `+back` / `-back` | Назад |
| `+left` / `-left` | Влево |
| `+right` / `-right` | Вправо |
| `+jump` / `-jump` | Прыжок / вверх в полёте |
| `+down` / `-down` | Вниз в полёте |
| `+speed` / `-speed` | Бег |
| `+duck` / `-duck` | Присесть |
| `+use` / `-use` | Взаимодействие с объектом |
